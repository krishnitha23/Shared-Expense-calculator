# Shared Expense Calculator

A beginner Python project that calculates how much each
person needs to pay when sharing food, rent and electricity expenses.

## Features

- Takes food expenses as input
- Takes rent as input
- Calculates electricity bill
- Divides the total expense among people

## Concepts Used

- Variables
- Input and output
- Data types
- Arithmetic operators
- Integer conversion
- Basic Python logic

## Built With

Python
